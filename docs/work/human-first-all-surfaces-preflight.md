# All-surfaces human-first preflight

The master is safe to start only through its serial execution inventory. Each listed implementation item has one observable owner or customer outcome, keeps backend actions authoritative, changes only its named module files and shared primitives when necessary, and requires a leaf frontend build plus an independent browser trace before it can close.

The sequence deliberately starts with shared attention/action affordances, then high-frequency decision surfaces, then discovery and personal-context surfaces. It does not permit cross-module copy/paste or a global CSS rewrite.

The execution inventory is the sole order of work. Each item names a child-plan task, bounded paths, dependencies, a leaf validation command, and an evidence boundary.
