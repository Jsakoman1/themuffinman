# Local tabs navigation analysis

The workspace rail currently renders backend-provided children for Work, Services, Things, People, and Rides. These children duplicate module routes and make the global rail grow as personal context grows. Business has established the preferred pattern: a stable module entry in the rail and local content tabs for the active module and selected business.

The program preserves all canonical routes and backend authorization. It changes only where route links are presented: the rail becomes module-only, and module pages own their persistent local tabs.
