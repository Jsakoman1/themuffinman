# Dora v0.9 goal readiness

## Goal objective

Make Dora measurably easier for Codex and a beginner to operate every day while preserving the v0.8 product boundary and approval gates.

## Prepared execution contract

- One master references five work plans plus an atomic-hardening plan.
- One inventory queues 18 items in a direct serial chain.
- Every item maps to one child task with matching ids, exact paths, a non-recursive leaf validation, an observable outcome, and an evidence boundary.
- Two remote side effects remain isolated in the final two approval-gated tasks.

## Required evidence before completion

- Two-project fixtures for all context, recommendation, impact, and status commands.
- A compatibility fixture for finding envelopes.
- A cache invalidation fixture against uncached output.
- A no-credential voice evaluation fixture.
- An independent accelerated-consumer proof.
- A reachable immutable v0.9 tag, then a separately approved MuffinMan pin.

## Conclusion

The program is ready for a new goal. Creating that goal authorizes only the strict serial work described in the plan; it does not authorize release or pinning until a later explicit approval.
