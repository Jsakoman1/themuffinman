# Dora v1.0 goal readiness

## Goal objective

Turn Dora v0.9's separate, verified mechanics into one discoverable, no-invention
Codex-first workflow from explicit idea through verifier-recorded work.

## Prepared execution contract

- One master references six child work plans.
- One inventory queues 20 items in a direct serial chain; only one item can run.
- Each item maps to one task with exact paths, observable outcome, leaf validation,
  evidence boundary, and explicit Dora-versus-product ownership boundary.
- The first item hardens this plan and inventory before implementation begins.
- Remote source acquisition, GitHub publication, tag creation, and consumer pinning are
  isolated in the final approval-gated tasks.

## Required evidence before completion

- Interactive and non-interactive independent `dora new` consumers.
- CLI registry/help/guide parity and two-project command outputs.
- Plugin-to-finding-to-impact-to-status-to-closeout evidence flow.
- Cache hit and invalidation proof from a declared plugin run.
- Valid and tampered source-descriptor plus no-mutation upgrade-preview fixtures.
- A fresh end-to-end independent consumer, immutable v1.0 tag, and separately approved
  MuffinMan pin.

## Conclusion

The program is ready for a new goal. Goal creation authorizes only strict serial local
implementation beginning with `harden-v10-program`; it does not authorize any external
source acquisition, publication, tag, remote write, or consumer pin.
