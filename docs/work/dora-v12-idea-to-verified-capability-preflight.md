# Dora v1.2 preflight

## Baseline

`470b6e9` pins MuffinMan to released Dora `v1.1.0`. v1.1 controls are baseline-only unless a v1.2 task changes their declared trigger surface.

## Sequencing decision

The interview contract must precede generated project creation. Generated knowledge and capability-package contracts must precede readiness. Readiness must precede a generated atomic work item. Codex ergonomics and stack/plugin work may use those contracts only after their consumer-facing ownership boundaries are explicit. Trace and release work closes last.

## Evidence decision

Each project-boundary feature requires two non-MuffinMan consumers. A schema or command test alone cannot prove generated projects retain distinct user instructions or product knowledge. Plugin isolation remains a research/contract task unless a real enforced sandbox is selected and independently evidenced.

## External boundary

Publishing, tagging, remote writes, and pinning remain draft tasks until separate explicit approval.
