# Dora v1.5 goal readiness

The v1.5 master has nine independently scoped work plans and one hardening plan.
Its serial inventory contains nineteen atomic tasks. Each task has exact required
paths, one direct predecessor, a leaf validation command, and an evidence boundary.

The prepared plan authorizes only controlled task start after goal creation. It does
not authorize a browser, database, package installation, backup/restore, deployment,
or any product-specific code by itself.
