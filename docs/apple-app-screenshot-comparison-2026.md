# Apple desktop comparison matrix — 2026

These are official Apple Support/User Guide reference pages used during the native-app redesign. TheMuffinMan borrows interaction grammar and information hierarchy, not Apple trademarks, proprietary icons, source code, or exact screens.

| Reference | Observable pattern to compare against | TheMuffinMan application |
|---|---|---|
| [Notes for Mac](https://support.apple.com/guide/notes/view-your-notes-apd8b73d28be/mac) | Folders/sidebar, note list with preview, selected note detail, search, pinning, tags, collapsible detail | Work, Things wishlist, Business content, Vision |
| [Calendar for Mac](https://support.apple.com/guide/calendar/welcome/mac) | Sidebar calendars, color-coded sources, day/week/month range views, event detail and reminders in one temporal surface | Unified Calendar and per-business Calendar |
| [Reminders for Mac](https://support.apple.com/guide/reminders/welcome/mac) | Lists/columns, smart lists, sections, sorting, completion gesture, scheduled items | Home attention, Work flows, saved searches |
| [Mail for Mac](https://support.apple.com/guide/mail/welcome/mac) | Triage-first sidebar/list/detail, categories, search, focused compose, reversible actions | Attention, Work, bookings, Chat |
| [Messages for Mac](https://support.apple.com/guide/messages/welcome-icht66ecaafe/mac) | Conversation sidebar and active thread, one compose action, inline shared content and context | Chat and related Work/Business/Booking context |
| [Safari for Mac](https://support.apple.com/guide/safari/customize-the-safari-window-ibrw1012/mac) | Quiet configurable toolbar, sidebar, smart search, tab groups, overflow when space is limited | Global shell, Search/commands, module navigation |
| [System Settings for Mac](https://support.apple.com/guide/mac-help/change-system-settings-mh15217/mac) | Stable settings sidebar, selected pane, concise summaries, settings search, focused controls | Profile, Settings, Business setup |

## Acceptance use

Every visual phase must attach fresh Chromium screenshots for light desktop, dark desktop, and mobile, plus interaction evidence for navigation, selection, preview/detail, search, context switching, and recovery. Existing screenshots are baseline only and cannot close a new phase.
