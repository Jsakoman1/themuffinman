# UI and accessibility blueprints

Use the catalog as a review checklist when a confirmed capability selects a UI blueprint. Select only the patterns required by that capability, then document the concrete behavior, copy, permissions, state transitions, and acceptance evidence in the consumer project.

The catalog is intentionally neutral: it does not prescribe branding, business terms, or a final visual design. A selected blueprint is not a completed interface and does not replace browser or accessibility testing.
