# IDC v0

IDC v0 is a Dora-owned, local, file-backed advisory workspace. It accepts only
explicit owner-selected source manifests and can render `research_dossier` and
`greenfield_product_delivery_baseline` outputs with provenance, claims,
assumptions, conflicts, missing context, stop conditions and promotion proposals.

IDC is not a Dora authority: it does not create or amend DecisionLog entries,
Master Plans, tasks, evidence or verified status. It does not modify Git or
product code, start Codex, execute a shell, inspect arbitrary repositories, call
the network, or retain a general personal-memory database.

For a bounded delivery request, Dora's deterministic triage returns no IDC need.
For wide research or greenfield discovery, triage can only recommend IDC; the
owner must explicitly authorize one current-request local render. Dora Bridge
remains read-only and never performs that render.
