# Session discovery

Read these project-owned sources before making a change:

1. `AGENTS.md`
2. `.dora/agent-project-profile.yaml`
3. `docs/product-brief.yaml` and `docs/domain-library.yaml`
4. `docs/project-memory.yaml` when present
5. The selected atomic work plan and its execution inventory

Use `bin/dora agent-session` for declared, cited, read-only navigation context. A Dora session does not start work, grant approval, mutate a project, or prove a capability is complete.
