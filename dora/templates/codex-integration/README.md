# Dora Codex integration

This optional directory is Dora-owned guidance for a Codex agent. It does not replace `AGENTS.md` or grant any additional authority.

Start with the project-owned `AGENTS.md`, then inspect the declared work through `bin/dora agent-session`, `bin/dora agent-next`, and `bin/dora capability-trace` where those records exist.

Use one bounded work item at a time. Record work state only through the project work controls, retain runtime and validation evidence separately, and request approval before external actions.
