# Codex project entrypoint

Read these sources before planning or changing implementation:

1. `.dora/agent-project-profile.yaml` — authority limits, commands, evidence, and work order.
2. `docs/product-brief.yaml` — user problem, intended outcomes, scope boundaries, risks, and open decisions.
3. `docs/domain-library.yaml` — domain vocabulary, invariants, permissions, workflows, and acceptance scenarios.

Work one bounded item at a time. Record passing validation evidence before treating an item as verified. Do not publish, deploy, change external state, or make other irreversible changes without explicit user approval.
